# Songyun Chen — Academic Homepage

An English-language academic website for Professor Songyun Chen at Guangzhou Maritime University.

**Features:** responsive design, selected DOI-linked publications, research and teaching sections, an accessible publication filter, light/dark mode, and a print-friendly academic CV. Pure HTML/CSS/JavaScript; no npm packages or Jekyll theme dependencies.

## Deployment

1. Create a public repository named `<your-github-username>.github.io`.
2. Upload this repository's files **to the repository root**, preserving the `assets/` directory.
3. Under **Settings → Pages → Build and deployment**, choose **Deploy from a branch** and select `main` and `/(root)`.
4. Wait for GitHub Pages to publish the site at `https://<your-github-username>.github.io/`.

For customization, publication updates, portrait replacement, and detailed GitHub instructions, read [README_中文部署指南.md](README_中文部署指南.md).

The `SC` illustration is a typographic monogram, **not a photograph of the researcher**. The CV is a selected profile and should be checked before publication.
